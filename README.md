# PYQ Adda
Made by a DU student, for DU students.

## Add a paper
Edit `papers.json` and add one entry per paper:

    [
      { "course": "B.Com (Hons)", "sem": 1, "year": 2023, "url": "https://link-to-paper.pdf" },
      { "course": "B.A. (Hons) English", "sem": 2, "year": 2022, "url": "https://link-to-paper.pdf" }
    ]

`course` must match the course name on the site exactly. Put a comma between entries, none after the last.
